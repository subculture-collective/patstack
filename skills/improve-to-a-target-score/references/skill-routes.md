# Companion procedures

Load a companion only under its stated condition. Current authorization and client-native tool contracts remain authoritative. Read the source once; avoid cycles and do not switch the active profile for a one-off reference.

| Skill | Relationship | When to load it |
|---|---|---|
| `style-web-ui` | optional | When the panel's fixes change web UI styling, layout or components. |
| `verify-implementation` | optional | When capturing UI screenshots or proving the improved work still behaves correctly. |
| `evaluate-llm-behavior` | optional | When the ruler is an eval of model or agent behavior that must be built first. |
| `review-code-changes` | optional | When the user wants a one-time multi-model verdict without changes. |
| `manage-git-and-prs` | optional | When kept changes go into a commit or pull request. |
